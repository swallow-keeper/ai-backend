# 영상 처리 위치

1차는 기기 안 처리를 전제로 합니다. 얼굴, 목 관심 영역, 움직임 특징, 삼킴 후보 시각은 앱이 계산합니다.

서버가 받는 카메라 정보는 다음뿐입니다.

- 이벤트 시각
- 트리거: `auto`, `manual`, `periodic`
- 신뢰도 0 이상 1 이하, 수동이면 없을 수 있음

영상 프레임, 얼굴 영상, 목 크롭은 업로드 API가 없습니다. 디스크와 로그에도 두지 않습니다.

## 서버 폴백은 구현하지 않음

기기 안 처리가 불가능할 때의 서버 폴백은 1차 코드에 없습니다. 나중에 넣는다면 아래를 모두 만족해야 하며, 동의 화면과 기획서에 영상 전송 사실을 숨기지 않습니다.

- TLS
- 목 영역만 낮은 해상도로 전송
- 메모리에서 처리하고 즉시 폐기
- 디스크와 로그에 프레임을 쓰지 않음
- 자체 호스팅. 외부 클라우드 영상 API로 보내지 않음

이 문서는 그 조건의 메모입니다. 수신 소켓, 임시 파일, 프레임 큐는 만들지 않습니다.
